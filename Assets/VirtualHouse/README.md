# 住宅概形モデル

## 添付画像からの再構築（現行）

現行の生成処理は `Editor/HouseTracedPlan.cs` です。画像内の階数を基準に、960×540画像の太線の端点を直接座標化しています（ファイル名の階数は逆）。75pxの尺度線を1.82mとして換算します。
太線区間だけ壁とColliderを生成し、点線には壁や格子を生成しません。1階17か所・2階9か所の開口について、生成時に壁Colliderとの重なりを検査します。更新図に合わせてDKと給湯スペースの間の壁を取り除き、東側の勝手口へ通れるようにしました。
2階は階段の位置を合わせて配置し、階段上に床を張らず、北側廊下に接続します。外観は `Editor/HouseTracedExterior.cs` で現行図面へ位置合わせして生成します。2026年9月30日の外観写真を参照し、灰色の切妻屋根、勾配のある下屋、赤茶色の軒先、白い外壁、濃灰色の腰壁、銀色サッシと窓庇を再構成しています。写真から分からない寸法・屋根勾配は推定、窓ガラスは簡略表現です。旧座標の外観・格子・玄関装飾は呼び出しません。下記の旧写真ベースの説明は以前の実装の記録です。

1階東側の8帖和室は `Editor/HouseEastJapaneseRoom.cs` で写真8枚を基に再構成しています。8枚の畳と濃色の畳縁、砂壁と柱梁、南側の障子、北側の出窓収納、西側の山水襖、棹縁天井と角形照明を配置し、中央に黒漆調・金縁の長方形ちゃぶ台を置いています。南側の縁側と橙色カーテンは、西隣の8帖和室前まで連続させています。写真だけで確定できない奥行きや建具幅は、図面上の約3.66m角へ収まるよう推定しています。

1階西側の8帖和室は `Editor/HouseWestJapaneseRoom.cs` で写真8枚を基に再構成しています。南側の4枚障子と欄間窓、東側の山水襖と山並みの透かし欄間、西側の砂壁と棹縁天井を配置しています。北側収納は低い床板のみのシンプルな形にし、和室側に張り出す収納・襖・奥壁を撤去しました。棚は西隣の納戸の奥（西壁沿い）に配置しています。西壁の北半分は納戸への開口を維持しています。`GenerateAndRenderWestJapaneseRoom` は開口内のRendererとColliderも検査します。中央は写真どおり家具を置かず、東和室のちゃぶ台が続き間越しに見える構成です。

洋室は `Editor/HouseWesternRoom.cs` で写真を基に簡略再構成しています。ベージュの壁、床とラグ、造付け収納と違い棚、暖炉風の飾り、壁灯を配置しています。寸法・位置は図面と写真からの推定で、布や床の細かな模様は省略しています。家具は `Prefabs/WesternArmchair.prefab`、`WesternSofa.prefab`、`WesternCoffeeTable.prefab` に保存し、シーンには置いていません。

生成されるカーテンは左右に寄せた開いた状態です。外窓は `ClearWindow` の透明マテリアルを使い、ガラスの背後にあった壁・外装も窓形に切り抜いています。外には現行の空と地面が見えます（実景の庭や周辺建物は未再現）。`RebuildWesternRoom` は再生成、窓開口と納戸開口の検査、家具プレハブの存在確認、洋室プレビュー出力を実行します。

`Virtual House > Regenerate Floor Plan Blockout` で現行モデルを再生成できます。歩行操作は従来どおりです。

以前階段下端に張り出していた平板天井は撤去し、玄関の下屋は階段外から始めて頭上を塞がない形状にしています。プレイヤーは身長1.8mのままです。`HouseBlockoutGenerator.ValidateStairWalk` は保存済みシーンのCharacterControllerを使って、ジャンプなしの降段・昇段を検証します。`ValidateServiceWalk` はDK→給湯スペース→屋外踏み場の往復を検証します。`RebuildAndValidateStairs` は生成・プレビュー出力と両テストを実行します。

書き直した1階・2階の間取り図と外観写真20枚を基にした、寸法確認用の住宅モデルです。

## 基準寸法

- 図面の2マスを1坪の一辺（約1.81818 m）として解釈
- 1マス = 約0.90909 m
- 壁高 = 2.7 m（仮定）
- 1階から2階まで = 3.0 m（仮定）
- 壁厚 = 0.14 m（仮定）

## シーン

`Assets/Scenes/HouseBlockout.unity`

内部ブロックアウトに加えて、写真から推定した外壁仕上げ、窓、玄関、庇、主屋根、下屋、雨樋を作成します。
玄関周りは写真を基に、緑色のモルタル土間、上がり框、木床廊下、真壁風の柱と砂壁、
格子建具、造付け下駄箱、木階段、手すり、暖色照明を再現しています。
ヒエラルキーの `外観_写真ベース` 以下は部位別に分かれており、個別に表示・寸法調整できます。
茶色い薄板は室内側の扉・襖の位置を示す目安です。

## 室内移動

Play ボタンで一人称の室内移動を開始できます。

- `WASD` / 方向キー: 移動
- マウス: 視点操作
- `Left Shift`: ダッシュ
- `Space`: ジャンプ
- `Esc`: マウスカーソルを解放（画面クリックで再開）

スマートフォンでは、画面左側のスティックをドラッグして移動、画面右側をスワイプして視点操作、
右下の `JUMP` でジャンプできます。スティックを端まで倒すとダッシュします。
室内を移動しやすいよう、扉・ドア・襖のモデルは生成しません。
玄関正面も扉なしの開口としてあり、そのままポーチ・屋外へ出られます。
階段上の2階床には吹き抜け開口と踊り場があり、テレポートなしで2階へ上がれます。
スマートフォンのWebGLビルドでは、ブラウザのタッチ対応を検出して同じ操作UIを表示します。

WebGLビルドはUnityメニュの `Virtual House > Build WebGL` から `docs/` に作成できます。
GitHub Pagesは `main` ブランチの `/docs` を公開元に使用します。
詳しい手順と公開ファイルの構成は、プロジェクト直下の `BUILD.md` を参照してください。通常のBuild ProfilesからのWebビルドにも、ファイル名と全画面表示の共通後処理を適用します。

## 再生成

Unityメニューの `Virtual House > Regenerate Floor Plan Blockout` から再生成できます。
`Virtual House > Render Floor Plan Preview` で、屋根を非表示にした真上からの確認画像を出力できます。
生成コード冒頭の寸法、`CreateFirstFloor` / `CreateSecondFloor` のグリッド座標、および
`CreateExterior` の窓・屋根座標を変更すると、実測値に合わせて調整できます。

## 現段階の推定箇所

- 写真だけでは決められない建物の絶対寸法（平面図グリッドを基準に推定）
- 屋根勾配、軒の出、庇の奥行き
- 外壁の細かな凹凸と経年変化
- 廊下と水回りの正確な幅
- 開口部の幅・高さ
- 階段の向き、段数、勾配
- 天井高、階高、壁厚
- 2階の1階に対する正確な位置
