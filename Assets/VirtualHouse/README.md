# 住宅概形モデル

添付された平面図を基にした、寸法確認用の初期ブロックアウトです。

## 基準寸法

- 図面の2マスを1坪の一辺（約1.81818 m）として解釈
- 1マス = 約0.90909 m
- 壁高 = 2.7 m（仮定）
- 1階から2階まで = 3.0 m（仮定）
- 壁厚 = 0.14 m（仮定）

## シーン

`Assets/Scenes/HouseBlockout.unity`

上から内部を確認できるよう、屋根と天井はまだ作成していません。茶色い薄板は扉・襖の位置を示す目安です。

## 再生成

Unityメニューの `Virtual House > Regenerate Floor Plan Blockout` から再生成できます。
生成コード冒頭の寸法と、`CreateFirstFloor` / `CreateSecondFloor` 内のグリッド座標を変更すると、写真や実測値に合わせて調整できます。

## 現段階の推定箇所

- 外壁の細かな凹凸
- 廊下と水回りの正確な幅
- 開口部の幅・高さ
- 階段の向き、段数、勾配
- 天井高、階高、壁厚
- 2階の1階に対する正確な位置
