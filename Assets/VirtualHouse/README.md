# 住宅概形モデル

平面図と外観写真20枚を基にした、寸法確認用の住宅モデルです。

## 基準寸法

- 図面の2マスを1坪の一辺（約1.81818 m）として解釈
- 1マス = 約0.90909 m
- 壁高 = 2.7 m（仮定）
- 1階から2階まで = 3.0 m（仮定）
- 壁厚 = 0.14 m（仮定）

## シーン

`Assets/Scenes/HouseBlockout.unity`

内部ブロックアウトに加えて、写真から推定した外壁仕上げ、窓、玄関、庇、主屋根、下屋、雨樋を作成します。
ヒエラルキーの `外観_写真ベース` 以下は部位別に分かれており、個別に表示・寸法調整できます。
茶色い薄板は室内側の扉・襖の位置を示す目安です。

## 室内移動

Play ボタンで一人称の室内移動を開始できます。

- `WASD` / 方向キー: 移動
- マウス: 視点操作
- `Left Shift`: ダッシュ
- `Space`: ジャンプ
- `Esc`: マウスカーソルを解放（画面クリックで再開）

スマートフォンでは、画面左側のスティックをドラッグして移動、画面右側をスワイプして視点操作、
右下の `JUMP` でジャンプできます。スティックを端まで倒すとダッシュします。
室内を移動しやすいよう、扉・ドア・襖のモデルは生成しません。
スマートフォンのWebGLビルドでは、ブラウザのタッチ対応を検出して同じ操作UIを表示します。

WebGLビルドはUnityメニュの `Virtual House > Build WebGL` から作成できます。

## 再生成

Unityメニューの `Virtual House > Regenerate Floor Plan Blockout` から再生成できます。
生成コード冒頭の寸法、`CreateFirstFloor` / `CreateSecondFloor` のグリッド座標、および
`CreateExterior` の窓・屋根座標を変更すると、実測値に合わせて調整できます。

## 現段階の推定箇所

- 写真だけでは決められない建物の絶対寸法（平面図グリッドを基準に推定）
- 屋根勾配、軒の出、庇の奥行き
- 外壁の細かな凹凸と経年変化
- 廊下と水回りの正確な幅
- 開口部の幅・高さ
- 階段の向き、段数、勾配
- 天井高、階高、壁厚
- 2階の1階に対する正確な位置
